# Publishing checklist

1. Create an empty GitHub repo named `intelligent-traffic-management` (public).
2. In this folder run:
   git init && git add . && git commit -m "Intelligent Traffic Management System"
   git branch -M main
   git remote add origin https://github.com/kayrie18/intelligent-traffic-management.git
   git push -u origin main
3. Repo Settings > Collaborators > Add people: stanslausphillimon@gmail.com
4. Repo Settings > Pages > Source: Deploy from a branch > Branch: main, folder: /docs > Save.
5. Wait a minute, then open https://kayrie18.github.io/intelligent-traffic-management/
6. Submit the repo URL and the Pages URL.

If you use a different repo name, replace "intelligent-traffic-management" in docs/*.html and README.md.
